Browser game: Firefox save resets reported

A player tested the same edited saves in different versions: Chrome and the downloaded game retained progress, while Firefox reverted it after a run. This points toward browser-game persistence, not a separate .sav format. The exact Firefox cause is still unconfirmed.

Safe import steps & troubleshooting

This refers to the browser used to play the game, not the browser used to open this editor. If Firefox is resetting progress, try playing and importing in Chrome or the downloaded version. This editor cannot change how the game autosaves.

Export a fresh game save, keep the untouched file separately, and then import the editor-modified save. An in-game import replaces your full account save, including Codex progress; it does not merge newer discoveries. For a persistence check, export immediately after importing, then export again after a run and compare. Don't clear browser site data while troubleshooting.

Zone editing requires progression initialized by the game for that class. If unavailable, enter the game with that class and export a new save first.
